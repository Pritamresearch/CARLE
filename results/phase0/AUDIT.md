3. **Field Test Clip Identification**: Of the available field test videos in `data/field_videos/`, only three clips have native $848 \times 478$ resolution: `india bolpur.mp4` (239 frames), `malaysia.mp4` (487 frames), and `sikim.mp4` (1,907 frames). Therefore, the 4th clip cannot be unambiguously determined from disk alone.
4. **PNG Baseline**: On the same 4-class nuScenes label maps ($900 \times 1600$), OpenCV PNG (compression level 9) achieves 26.73 Kb/frame (431.0x vs raw 8-bit, 107.7x vs raw 2-bit log2(C)), at 19.08 ms CPU encoding latency. In comparison, CARLE Canonical (class-preserving with real 7-byte binary serialization) achieves 45.70 Kb/frame (252.1x vs raw 8-bit, 63.0x vs raw 2-bit).

## 3. Method vs. Code Mismatch

### (a) What Each Codebase Computes
- **`legacy/`**: Computes $D_{xor} = F_t \oplus F_{t+1}$. It flattens the XOR map and run-length encodes every region, outputting triples $[start, length, value]$. The byte size is estimated by the formula $B_{comp} = len(rle) \times 6$.
- **`legacy_local/` (`main_PIDNET.py`)**: Implements Equation 2 from the paper:
  $$D(i, j) = \begin{cases} F_{t+1}(i, j), & \text{if } F_{t+1}(i, j) \neq F_t(i, j) \\ 0, & \text{otherwise} \end{cases}$$
  It encodes only non-zero runs and serializes each entry as a 7-byte binary packet: `uint32 start` (4B) + `uint16 length` (2B) + `uint8 class` (1B).

### (b) 3×3 Toy Example Proving Decoder Failure & Class Corruption in Legacy
Consider a $3 \times 3$ grid with classes: 0 = Background, 2 = Pedestrian, 3 = Vehicle.

**Previous frame $F_t$** (pedestrian at center):
$$F_t = \begin{pmatrix} 0 & 0 & 0 \\ 0 & 2 & 0 \\ 0 & 0 & 0 \end{pmatrix}$$

**Current frame $F_{t+1}$** (pedestrian moves to $(1,2)$, vehicle enters at $(1,1)$):
$$F_{t+1} = \begin{pmatrix} 0 & 0 & 0 \\ 0 & 3 & 2 \\ 0 & 0 & 0 \end{pmatrix}$$

**Bitwise XOR Computation ($D_{xor} = F_t \oplus F_{t+1}$):**
- At $(1,1)$: $2 \oplus 3 = 1$ (**Synthetic Corrupted Class!** Label 1 does not exist in the vocabulary $\{0, 2, 3, 4\}$).
- At $(1,2)$: $0 \oplus 2 = 2$.
- All other pixels: $0 \oplus 0 = 0$.
$$D_{xor} = \begin{pmatrix} 0 & 0 & 0 \\ 0 & \mathbf{1} & 2 \\ 0 & 0 & 0 \end{pmatrix}$$

**Legacy Decoder Execution (`decode_rle.py`):**
The decoder executes `mask[start:start+length] = value` directly from the RLE code without any reference to $F_t$:
$$\hat{F}_{decoded} = \begin{pmatrix} 0 & 0 & 0 \\ 0 & \mathbf{1} & 2 \\ 0 & 0 & 0 \end{pmatrix} \neq F_{t+1} = \begin{pmatrix} 0 & 0 & 0 \\ 0 & \mathbf{3} & 2 \\ 0 & 0 & 0 \end{pmatrix}$$
`decode_rle.py` fails exact equality (`np.array_equal` returns `False`). It reconstructs the differential difference map rather than the true scene, and XOR introduces invalid phantom class IDs whenever one moving object occludes or replaces another.

In contrast, **Class-Preserving Differencing (Eq. 2 & `main_PIDNET.py`)**:
$$D_{canon}(1,1) = 3, \quad D_{canon}(1,2) = 2, \quad \text{all unchanged} = 0$$
The decoder directly writes non-zero values into the persistent semantic world map:
$$\hat{F}_{t+1} = \text{copy}(F_t); \quad \hat{F}_{t+1}[1,1] = 3; \quad \hat{F}_{t+1}[1,2] = 2 \implies \hat{F}_{t+1} \equiv F_{t+1}$$
This is guaranteed lossless, class-preserving, and requires 0 arithmetic decoding operations.

## 6. PNG Baseline on 4-Class nuScenes Label Maps

To establish a solid, rigorous baseline on the exact same 4-class nuScenes label maps ($900 \times 1600$), we implemented and evaluated OpenCV PNG (compression level 9):

| Codec / Representation | Compressed Bytes / Frame | Bits / Frame (Kb) | CR vs Raw 8-bit ($11,520 \text{ Kb}$) | CR vs Raw 2-bit ($2,880 \text{ Kb}$) | CPU Latency (ms) | Notes |
|---|---|---|---|---|---|---|
| **Raw 8-bit** | 1,440,000 | 11,520.0 | 1.0× | 0.25× | 0.00 | 1 byte per pixel |
| **Raw 2-bit ($\log_2 C$)** | 360,000 | 2,880.0 | 4.0× | 1.0× | 0.00 | Theoretical entropy floor for $C=4$ |
| **PNG (OpenCV level 9)** | **3,341.2** | **26.73** | **431.0×** | **107.7×** | **19.08** | Intra-frame Deflate (LZ77 + Huffman) |
| **CARLE Canonical (Class-Preserving)** | **5,713.0** | **45.70** | **252.1×** | **63.0×** | **1.24** | Real 7-byte binary packets `(start, len, cls)` on differential map |
| **CARLE Legacy (XOR + `len*6`)** | 19,424.2 | 155.39 | 74.1× | 18.5× | 1.15 | Includes background zero runs and XOR artifacts |
| **CARLE Paper Reported (nuScenes 2,424 avg)** | 5,431.7 | 43.50 | 265.1× | 66.3× | 60.40 (incl. seg) | Historic submitted paper table entry |

Key takeaway: PNG level 9 achieves 26.73 Kb/frame because 2D Deflate compresses huge contiguous zero background areas very efficiently for single frames. However, PNG is purely intra-frame and lacks goal-oriented receiver state updates. CARLE transmits differential triplets that directly overwrite the receiver's persistent semantic world map.
